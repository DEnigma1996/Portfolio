# Portfolio + Learning Dashboard + Tech Blog

This project is a React + TypeScript + Vite app with URL routing for:

- `/` → Portfolio home (hero/about/skills/projects/experience/contact)
- `/learn` → Java learning dashboard
- `/learn/sessions` → Deep link to sessions tab
- `/learn/planner` → Deep link to planner tab
- `/learn/blog` → Deep link to dashboard blog/social tab
- `/blog` → Tech blog listing
- `/blog/:slug` → Single blog post page

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```
